## 4. How to deploy and verify from now on

From `artifacts/aips-landing`:

```bash
bash scripts/deploy-live.sh            # gates → deploy → verify live
bash scripts/deploy-live.sh --wait     # same, but auto-retries until a slot frees
bash scripts/deploy-live.sh --verify   # check the live site only
bash scripts/deploy-live.sh --dry-run  # gates only, no deploy
```

- **Gates run before spending a deploy slot:** catalog validator → typecheck →
  production build. Broken work can't consume a slot or reach production.
- **Live verification doesn't trust HTTP 200.** Every unmatched path on this SPA
  returns 200 and renders client-side — that's exactly how a blank `/pricing`
  shipped unnoticed. For a real render check, run the headless sitemap crawl.

**Rule for catalog edits:** after changing `data/products.json`, run
`node scripts/generate-concierge-catalog.mjs` and commit `api/_catalog.json`
with it, or the chatbot's knowledge goes stale. The validator enforces this.

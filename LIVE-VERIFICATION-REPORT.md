## 💡 **TROUBLESHOOTING GUIDE**

### **If Video Doesn't Play**

**Check:**
1. Supabase bucket exists: Storage → videos
2. Files are uploaded and public
3. File names match exactly (no spaces)
4. Browser cache cleared (Ctrl+Shift+Del)
5. Try different browser

**Fix:**
- Verify Supabase URLs in component
- Confirm CDN access enabled
- Check CORS headers
- Test file URL directly in browser

### **If Video Loads Slowly**

**Check:**
1. CDN status: https://status.supabase.com
2. Browser network tab (F12)
3. File sizes (should be 2.5MB WebM)
4. Network connection quality

**Fix:**
- Wait for CDN cache to populate
- Clear browser cache
- Try different network
- Check Supabase logs

### **If Only Mobile Has Issues**

**Check:**
1. Mobile file uploaded (homepage-hero-mobile.webm)
2. Mobile resolution correct (600×338)
3. Mobile device cache cleared

**Fix:**
- Verify mobile variant in Supabase
- Force refresh on mobile (Ctrl+F5)
- Try different mobile browser

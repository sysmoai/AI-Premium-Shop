# Off-site SEO Playbook — AI Premium Shop (2026-08-02)

On-site is now largely done (207/271 URLs serve real static HTML, internal
linking dense, FAQ/Product/Breadcrumb schema live). Off-site cannot be done by
an agent alone — every item below needs the CEO's accounts or identity. Ranked
by impact per hour.

## P0 — do this week (biggest impact, ~1 hour total)

1. **Google Search Console** (15 min, single biggest lever)
   - Add property `aipremiumshop.com` (DNS TXT verification — you hold Google
     Cloud DNS access).
   - Submit `https://aipremiumshop.com/sitemap.xml` (271 URLs).
   - Without this, Google discovers pages on its own schedule; with it, the
     157 new product pages get crawled in days instead of months, and we see
     exactly which queries bring impressions.
2. **Bing Webmaster Tools** (5 min) — import from GSC with one click. Bing
   powers ChatGPT/Copilot answers, which BD users increasingly ask for
   "buy ChatGPT Bangladesh".
3. **Google Business Profile** (20 min) — "AI Premium Shop", category
   Software/Subscription service, WhatsApp number, aipremiumshop.com. Local
   pack ranking for "ChatGPT price Bangladesh"-type searches.

## P1 — this month

4. **Facebook page + group posting cadence.** BD buying intent lives on
   Facebook. Weekly: one product-price post (link to the product page), one
   how-to post (link to a guide). The Notion Content Engine DB already has
   drafts to reuse.
5. **YouTube Shorts / TikTok**: 30-second "how to pay for ChatGPT with bKash"
   walkthroughs → links in description to /how-to-order. These queries have
   real volume and zero good BD answers.
6. **Directory/citation backlinks** (free, one-time): Trustpilot profile,
   Facebook page website field, LinkedIn company page, local BD directories
   (bdtradeinfo, businessdirectorybd). Consistent NAP: name, WhatsApp,
   aipremiumshop.com.
7. **Quora + Reddit answers** (r/bangladesh, r/freelancerbd): answer "how do I
   pay for X from Bangladesh" honestly, link the specific product page.
   2-3/week, written personally, not spam.

## P2 — compounding

8. **Guest posts / interviews** on BD tech blogs (TechShohor, Banglatech) —
   founder story: "why Bangladeshis can't pay for AI tools and what we built".
9. **Affiliate/partner links**: the Notion Apply-Tracker DB lists candidates;
   each accepted partner is a backlink + referral channel.
10. **WhatsApp Channel + broadcast list** for price-drop announcements —
    retention, not SEO, but it compounds repeat purchases.

## What NOT to do

- No purchased backlinks/PBNs — a BD e-commerce site is exactly the profile
  Google's spam team pattern-matches.
- No AI-spun guest posts at scale.
- Don't split content across a second domain; everything on aipremiumshop.com.

## Measurement

GSC weekly: impressions/clicks for "price bangladesh" cluster. The 50k/mo
organic target needs GA4 live to be trackable at all — currently we cannot
measure visitors, only rankings.

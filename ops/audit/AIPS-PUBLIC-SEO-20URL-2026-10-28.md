## Evidenced findings
- **P1 CONFIRMED CURRENT PUBLIC:** `/chatgpt-vs-gemini` has public title and H1 `ChatGPT vs Google in Bangladesh`, while governed `ops/seo/support-cluster-ownership-2026-09-07.json` maps this decision to Google AI Pro/Gemini Advanced. Source cause in `sanitize-comparison-prerender.mjs` used generic Google brand. Draft [PR #152](https://github.com/sysmoai/AI-Premium-Shop/pull/152) changes the generated comparison product label; pending full CI/staging/CEO release approval.
- **P1 CONFIRMED SOURCE TRUNCATION:** `sanitize-product-prerender.mjs` and `prerender-informational-products.mjs` inserted literal `…` in title for length. PR #152 now shortens generic boilerplate without inserted title ellipsis, respecting the existing 70-character product title rule. The product meta-description 158-character gate remains unchanged, and description ellipses are a separate copy-quality concern.
- **P1 COMMERCIAL LABEL CHECK:** current `/products` extractor lists ChatGPT Business as Personal while `/chatgpt-business-bangladesh` has per-user Team/Workspace details. Existing [PR #95](https://github.com/sysmoai/AI-Premium-Shop/pull/95) is relevant; do not duplicate or change protected business facts without current SSOT/CEO consent.
- **P1 CONDITIONAL SCHEMA:** dated Oct16 GSC owner-side report showed missing Product image on two money pages; current connected SMEPost integration is `siteUnverifiedUser`, so current issue not verified. Merchant markup/images only where eligible, verified, licensed and truthful. See [AIPS issue #135](https://github.com/sysmoai/AI-Premium-Shop/issues/135) and [approved media issue #49](https://github.com/sysmoai/AI-Premium-Shop/issues/49).
- **P1 CONDITIONAL HOST REDIRECT:** Claude operator reported HTTP and www 200 instead of first-hop 301/308. Independent first-response chain not verified. Canonical tags are present, not proof that Google chose them. Test host/path/query redirect before proposing Cloudflare rule and require production change approval.
- **P1 CONDITIONAL RENDER:** some initial product pages have only 139–164 words (operator). Do not infer thin *indexed* content from initial HTML. Compare raw source, hydrated DOM, and Search Console URL Inspection. Google crawls, renders, indexes JavaScript.
- **P2 SOCIAL:** shared default OG image across this sample is a social-preview optimization opportunity, not directly a Google ranking blocker. 0 extracted image links does not mean no React-rendered images. Do not invent vendor imagery or license.
- **P2 SITEMAP:** 280 URLs with July–September lastmod are operator-reported. Lastmod is incorrect only where meaningful changes postdate the XML value; verify dates from actual production/publication.
- **P0 TRUST/TRUTH:** old web cache showed obsolete shared account offers/prices. Current `/capcut-pro-bangladesh` and `/chatgpt-pro-bangladesh` pages explicitly say **no current purchasable plan**. Current `/chatgpt-plus-bangladesh` says Personal BDT 3,390/month. Do not conflate dated old cache with current live commercial inconsistency; cross-check current product/FAQ/terms and source-of-truth. Current `/gemini-advanced-bangladesh` meta says Personal and Shared; flag exact current access eligibility for owner review.
- **MEASUREMENT UNKNOWN:** 16 Oct GSC owner account was verified then, but current linked SMEPost property is unverified. Cannot claim current clicks, sales attribution, margin or #1 rank.

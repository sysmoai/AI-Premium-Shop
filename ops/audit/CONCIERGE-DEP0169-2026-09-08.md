# Concierge DEP0169 isolation — 2026-09-08

## Incident

Production `/api/concierge` emits Node DEP0169 (`url.parse()` legacy API) on cold start under Node 24. The warning reproduced on production deployment `dpl_75ttas3dBhjYjcwDSaRuNfy5SAxn` at merge SHA `2320528e15f676d3853724eda7bfb0d7bd8383db` after the optional conversation store had already migrated from deprecated `@vercel/postgres` to `@neondatabase/serverless`.

## Isolation evidence

- `/api/feedback` imports `_store.js` but did not create a new DEP0169 occurrence during the comparison request.
- `/api/insights` imports `_store.js` and `_auth.js` but did not create a new DEP0169 occurrence during the comparison request.
- Repository search found no direct application call to `url.parse()`, `url.resolve()`, `url.format()`, or `require("url")`.
- The concierge runtime uniquely loaded governed JSON assets from filesystem URLs derived from `import.meta.url`.

## Experiment 1 — concierge entry point

PR #89 removed the unnecessary `fileURLToPath()` conversion from `api/concierge.js` and passed `new URL(name, import.meta.url)` directly to `fs.readFileSync()`. Node's supported filesystem API accepts a WHATWG `file:` URL as the `path` argument.

### Result: not the full root cause

Production deployment `dpl_9HgiqFpBQQU3zMccaoeJ3KjKN1gF` at merge SHA `700eca0ad7982cfbe7135ca72616b716de485b44` passed normal release gates and served `/api/concierge` successfully. Before the cold-start request, the 15-minute DEP0169 snapshot was count `1`, last `2026-09-07T20:54:40Z`, on the previous deployment. After the request, delayed aggregation advanced the group to count `2`, last `2026-09-07T21:02:57Z`, with `lastDeployment=dpl_9HgiqFpBQQU3zMccaoeJ3KjKN1gF`.

Therefore PR #89 was a valid API simplification but did not eliminate DEP0169.

## Experiment 2 — concierge-only knowledge asset tracer

PR #90 removed the remaining `fileURLToPath()` conversions from `api/_knowledge.js` while retaining direct `new URL(..., import.meta.url)` filesystem reads. The function still served correctly and all release gates passed.

### Result: still reproduced

Production deployment `dpl_3nzByq6xwKzmwGYmN7iqDnkwR4go` at merge SHA `af617684ab60f10202f2ae90a57e32c98936188e` was live with publication allowed. Immediately before the controlled `/api/concierge` cold start, the 15-minute DEP0169 snapshot was count `2`, last `2026-09-07T21:02:57Z`, on the prior deployment. After the cold-start request, aggregation advanced the group to count `3`, last `2026-09-07T21:08:53Z`, with `lastDeployment=dpl_3nzByq6xwKzmwGYmN7iqDnkwR4go`.

Therefore merely removing `fileURLToPath()` is insufficient. The remaining common runtime mechanism is the `import.meta.url`-based filesystem asset load itself.

## Experiment 3 — static JSON modules, no runtime URL/path conversion

Replace the concierge filesystem loader with Node 24 native static JSON module imports using mandatory import attributes:

```js
import catalog from "./_catalog.json" with { type: "json" };
import policy from "./_policy.json" with { type: "json" };
```

Remove the now-redundant `_knowledge.js` runtime asset tracer. Static module specifiers make the governed JSON dependencies explicit to the Node/Vercel bundler without `fs.readFileSync()`, `new URL()`, or `import.meta.url` at runtime.

This is a controlled hypothesis until all normal exact-head release gates pass, the Vercel preview is READY, the exact production SHA is live, `/api/concierge` is cold-started, and a delayed Vercel runtime-error comparison shows that the DEP0169 timestamp/count did not advance.

## Rollback / continuation rule

If DEP0169 reproduces again, keep the evidence, do not downgrade Node merely to hide the warning, and continue isolating the concierge-only bundled graph. If it does not reproduce after delayed comparison, mark the incident resolved with the exact production deployment and verification timestamp.

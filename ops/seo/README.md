# AI Premium Shop SEO Operations

This directory stores durable SEO operating evidence and intent ownership for `aipremiumshop.com`.

Authority rules:

1. `ops/ssot/` remains authoritative for business, commercial, provider and publication truth.
2. Files here may define search intent, URL ownership, crawl/index findings, competitor observations and SEO execution order.
3. Files here must never create or override protected facts such as price, availability, access model, delivery, refund/warranty, provider authorization, payment support, ratings or reviews.
4. Search/SERP snapshots are time-bound observations, not permanent ranking facts.
5. Current Search Console and transaction data, when available, supersede qualitative priority assumptions.
6. Every production SEO change still follows `ops/ssot/autonomy-policy.json` release gates.

- `SEO-GROUND-TRUTH-2026-09-03.md` — verified production/search baseline and current execution diagnosis.
- `keyword-ownership-2026-09-03.json` — primary URL ownership and first Tier-A product set.
